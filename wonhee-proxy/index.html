01 / What has been tested

A working foundation,
built on real devices.

Recent root-assisted test sessions demonstrated two simultaneously active WireGuard kernel tunnels, separate route selection and reachability to a private home service. These are development results, not independent leak-proof certification.

TESTED / 01

Two active tunnels

Root-assisted HOME and Internet WireGuard interfaces operated at the same time in device testing, with separate profile choices.

TESTED / 02

Split network routes

Policy routes directed private-service traffic to the home tunnel and selected internet traffic to another tunnel; IPv4/IPv6 route observations are available.

TESTED / 03

Diagnostics and control

Connection state, handshake and traffic counters support troubleshooting. Import, selection and manual connection controls continue to be refined.

Connection is not the same as protection.

Passing handshakes and route checks does not verify DNS privacy, ad/tracker blocking, full-device routing or a working kill switch.

IN PROGRESS / DNS

DNS that can be audited

DNS policy integration and encrypted resolution are under development. DoH/DoQ/DoH3, strict no-fallback behavior and independent leak tests are not yet validated.

PLANNED / FILTERING

Block with visibility

Ad/tracker filtering, configurable lists and a blocked-request count are on the roadmap. No verified protection percentage is claimed.

PLANNED / SAFETY & UI

Confidence at a glance

A dependable kill switch, emergency stop, clearer multi-profile management and a persistent up/down-speed notification remain product work.

03 / Privacy boundaries

Honest about what's unfinished.

Experimental software, not a verified privacy shield.

Root-assisted multiple tunnels and route selection are under test. DNS leaks, IPv6 fallback, firewall enforcement, reboot recovery and no-direct-fallback behavior require independent audits before any security guarantees. Some features require root and are not available through Android's ordinary single-VPN mode.

04 / Distribution

Building toward a safer beta.

Wonhee Proxy is being tested with development APKs and an evolving root-assisted backend. Public release packaging and privacy claims will wait for stronger validation. There is no public APK advertised here yet.
